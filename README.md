# TypeR

O **TypeR** é uma extensão para Adobe Photoshop que facilita o trabalho de typesetting: organizar textos, aplicar estilos e posicionar falas nas páginas.

Esta versão é uma **personalização do TypeR**, desenvolvida a partir do projeto de **Swirt**. Ela reúne as ferramentas de texto da extensão com ajustes adicionais para o fluxo de edição de mangás e manhwas.

## Funcionalidades

- **Texto por linha:** cole ou escreva as falas no painel e navegue entre elas durante o trabalho.
- **Estilos de texto:** crie, edite e organize estilos em pastas para reutilizar fontes, tamanhos e outras configurações.
- **Tags de estilo:** associe tags às falas para selecionar estilos automaticamente.
- **Criação e posicionamento:** crie camadas de texto a partir da linha ativa e posicione-as em uma área selecionada no Photoshop.
- **Modo multi-bolha:** registre múltiplas seleções para trabalhar com vários textos.
- **Atalhos e configurações:** personalize o fluxo de trabalho e importe ou exporte configurações e estilos em JSON.
- **Navegação entre páginas:** trabalhe com documentos PSD e avance entre páginas pelo painel.
- **Zoom da página:** use os botões ou a roda do mouse para alternar entre os níveis disponíveis.
- **Idiomas e aparência:** escolha entre os idiomas e temas disponíveis na extensão.

## Requisitos

- Windows.
- Adobe Photoshop com suporte a extensões CEP.
- Um documento aberto no Photoshop para criar ou ajustar camadas de texto.

## Instalação

1. Baixe o pacote completo na seção **Releases**.
2. Extraia o ZIP.
3. Feche o Photoshop.
4. Execute **`Instalar.cmd`** e siga as instruções.
5. Abra o Photoshop e procure o **TypeR** em **Janela > Extensões**.

Mantenha a pasta `TypeR_Personalizado` e os arquivos do instalador juntos após a extração.

## Como começar

1. Abra uma página no Photoshop e inicie o painel do TypeR.
2. Escreva ou cole o texto no bloco de texto do painel.
3. Crie um estilo ou selecione um estilo existente.
4. Faça uma seleção na área em que deseja posicionar a fala.
5. Use o comando de colar do TypeR para criar e posicionar a camada de texto.
6. Avance para a próxima linha e continue o processo.

As configurações e os estilos podem ser exportados para backup ou transferidos para outra instalação.

## Sobre esta versão

O pacote personalizado está identificado como **1.0.10** e informa como base o TypeR **2.5.0**. Entre seus ajustes estão controles de zoom da página, recursos para trabalhar com múltiplas páginas e melhorias no ajuste de tamanho do texto.
